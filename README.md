# Expense Tracker App

A simple Android application that allows users to track daily expenses.

## Features
- Add new expenses
- View expense list
- Edit and delete expenses
- Monthly total calculation
- Data stored locally using Room database

## Tech Stack
- Kotlin
- Android Studio
- Room Database
- RecyclerView
